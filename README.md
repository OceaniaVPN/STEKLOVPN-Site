# STEKLOVPN

Главная страница проекта STEKLOVPN.

## Структура

- `index.html` — адаптивная главная страница с четырьмя каталогами и сезонными темами.
- Каталог «Прокси» ведёт в отдельный репозиторий [Proxy_sait](https://github.com/OceaniaVPN/Proxy_sait).
- Остальные три каталога пока отмечены как «В разработке».

## Сезонное оформление

Посетитель может выбрать весну, лето, осень или зиму. Выбор сохраняется в локальном хранилище браузера на этом устройстве. Это переключатель оформления сайта, а не закрытая административная панель.

## Публикация через GitHub Pages

В репозитории открой **Settings → Pages** и выбери **GitHub Actions** в разделе Build and deployment. Workflow `.github/workflows/pages.yml` публикует сайт при обновлении ветки `main`.

После успешной первой публикации адрес главной страницы будет:

`https://oceaniavpn.github.io/STEKLOVPN-Site/`

Каталог прокси остаётся отдельным сайтом и не изменяется этим репозиторием.
